# One Word, One Username, One Reward

Entry for the make.fun bounty **One Word, One Username, One Reward** (slug `u-rusdyxbt-one-word-one-username-one-reward-1a191fae`).

The program (`main.ts`) writes a single word to `entry.txt`: the entrant's own make.fun username, `adhiejoey` — one word, no spaces, no trailing newline, plain ASCII.
